# NSW Analysis of Extreme Rainfall

This repository contains an analysis of extreme rainfall across New South Wales (NSW) using precipitation data from the NARCliM2.0 climate dataset.

The analysis derives the **RX1day (Maximum 1-day Precipitation)** extreme rainfall index, consistent with the ET-SCI climate indices, and investigates spatial and temporal patterns and trends in extreme rainfall.

## Objectives

- Process NARCliM2.0 daily precipitation data for NSW.
- Derive the RX1day extreme rainfall index.
- Examine spatial patterns of extreme rainfall across NSW.
- Analyse temporal variability in RX1day.
- Estimate trends in extreme rainfall through time.
- Identify areas showing increasing or decreasing RX1day tendencies.

## Data

The climate data used in this analysis are from **NARCliM2.0**.

Spatial boundary data are used to define the analysis region and support regional masking and mapping.

## Climate Extreme Index

### RX1day — Maximum 1-day precipitation

RX1day represents the maximum daily precipitation amount within a specified period. It is commonly used to assess the intensity and variability of short-duration extreme rainfall events.
